# Feedback decisions

All three supplied sets of feedback were reviewed, including the attachment.

| Feedback | Decision in this edition |
|---|---|
| Sessions, group memory, no repetitive packs | Built. Persistent named groups, player rotation, canonical answer history, explicit exhaustion. |
| Real team scoring | Built. Balanced alternating team turns, including uneven rosters, cumulative totals, final results, adjustable laps. |
| Co-op for social events | Built. Shared target and turn rotation. Clock stops for handoffs. |
| One Clue Each | Built. Named clue-giver rotation (or clockwise room order for quick play), Next clue-giver and Skip me. |
| Forbidden Words | Built with 290 authored answer sets. Missing clue sets are excluded, never filled with generic placeholder bans. |
| Streak time bonus | Built for quick/co-op only, capped at +10 seconds; competitive modes retain equal base time. |
| Difficulty bands and quiet handicaps | Built. Per-player difficulty/time in setup; not announced on the answer screen. Ramp switches bands as the round progresses. |
| Reliable tilt, tap backup, haptics | Built. Time-based confirmation, neutral rearming, sensitivity choices, on-demand permission/test, input cooldown, tap backup. Physical-phone acceptance pending. |
| One word, acting, voices | Built as reusable rules. Voices are fictional performance styles, avoiding pressure to mimic a real ethnicity or national group. |
| Pass limits and penalties | Built, both off by default. Challenge is a separate honest-room judgment and can be reviewed after a round. |
| Better reveal and playback | Card reveal and detailed correction list built. Video not included. |
| Custom list import, export, link sharing | Built. Review before saving imported/shared content; plain-text/JSON formats; errors for invalid cards; deduplication. |
| Broad and deep local decks | Built from existing game/place/landmark/photo repos and new curated Vermont-themed material. 30 local collections. |
| Non-text cards | 38 real Burlington photo prompts and a song humming deck. No remote audio playback or photo-identification claim. |
| Big-group visibility | Same-browser room display for a second monitor/projector. Explicitly not a cross-device room or live online lobby. |
| Microphone answer detection | Deferred. Speaker ambiguity, near-matches, overlapping voices and browser/network support need actual room trials. Tap/tilt is reliable fallback. |
| Mic banned-word detection | Deferred. Honor-system challenge and score corrections included. |
| Video highlights | Deferred. Camera consent, recording UI, storage, codecs, and overlay timing need a separate scoped implementation. |
| Community submissions/upvotes/live deck co-building | Deferred. Needs identity, moderation, and durable multi-user storage. Export/import/link sharing work now. |
| Random gold/don't-skip cards | Excluded from the core. They make competitive scores less comparable and add rules during time pressure. |
| Physical relay mid-round | Replaced by paused handoffs between turns. Avoids passing a live clock and phone through a crowded table. |
| Freshness based on elapsed months | Stricter default: no repeats until the group explicitly starts a new cycle. No undocumented resurfacing. |
| Offline, no account, battery | Game state is local; fonts/media self-hosted; offline save; no continuous audio/mic/video; sensors detach when inactive. Private host authentication is separate from the game's account-free design. |

The screen is intentionally a deck shelf and play surface rather than a promotional landing page. Mobile play uses high-contrast cards, large fixed controls, a readable timer, and a mask while paused. The desktop room screen shows live points as well as the card and shared clock.

## Expanded goal: levels and breadth

The extension adds 20 authored decks (10 regional and 10 general), bringing the shelf to 60. It adds an actual 36-level challenge trail with six themed paths, fixed time/rules, earned next-level access, three star thresholds, group-specific progress, attempt counts, and personal bests. Every level has enough eligible authored content to reach its gold target. Progress does not clear or circumvent no-repeat memory.
